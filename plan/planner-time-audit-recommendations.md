# Аудит модуля Planner + Time (MVP)

Дата: 2026-03-10

## 1) Что уже соответствует `plan/plan.md`

- `Tasks`: есть создание, редактирование, статусы, подзадачи, заметки.
- `Tasks`: есть сортировка по приоритету и дедлайну.
- `Time`: выбор категории обязателен перед стартом.
- `Time`: задача опциональна.
- `Time`: есть ручной ввод интервала.
- Стиль: минималистичный тёмный UI, без перегруза аналитикой на экране таймера.

## 2) Что сейчас в зоне доработки

- Фильтр `overdue` в списке задач не выведен в UI.
- В деталях задачи не выведено фактическое время по задаче.
- Нет отдельного пользовательского экрана `Time Log` (лента интервалов за день).
- Нет мягких уведомлений (старт дня/прогресс).
- Нет e2e/юнит-покрытия критического сценария.

## 3) Исправления в текущем цикле

- Planner:
  - исправлена логика списка, чтобы подзадачи не пропадали из-за фильтра статуса;
  - подзадачи всегда с серым индикатором (без наследования цвета приоритета);
  - убран лишний счётчик в header, оставлена сортировка;
  - улучшен верхний отступ/типографика для снижения риска визуального среза текста и цифр.
- Task details:
  - убрана кнопка `Сохранить`;
  - включено автосохранение: дедлайн, приоритет, категория, заметки (с debounce);
  - дедлайн сохраняется сразу после подтверждения в календаре.
- Time:
  - переработан flow управления сессией:
    - до старта: `Начать фокус`;
    - в процессе: `Пауза`;
    - на паузе: `Продолжить` и `Завершить`;
  - убрана карточная обёртка вокруг круга, оставлен цельный фон.

## 4) Рекомендации (что добавить/убавить)

### Добавить

- Экран `Time Log` как отдельный таб/экран с быстрым редактированием интервалов.
- В деталях задачи блок `Потрачено сегодня/всего` (из `time_entries` по `taskId`).
- Быстрые шаблоны сортировки в Planner: `Приоритет`, `Дедлайн`, `Сначала без дедлайна`.
- Мягкие уведомления (2 типа):
  - старт дня;
  - вечерний прогресс задач.

### Убрать/упростить

- Не добавлять сейчас сложные метрики и длинные графики на `Home`.
- Не добавлять multi-user механику до стабилизации single-user сценария.
- Не добавлять сложные статусы задач сверх `todo/done` на MVP.

## 5) Приоритет следующей итерации

1. Достроить `Time Log` (просмотр/редактирование/удаление).
2. Показать потраченное время в деталях задачи.
3. Довести фильтры Planner до полного набора (`overdue`).
4. Добавить мягкие уведомления.
5. Закрыть базовый e2e-флоу (`Home -> Time -> Planner -> Summary`).
