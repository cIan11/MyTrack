# Аудит и рекомендации: текущий продуктовый курс

Дата: 2026-03-11

## 1) Что зафиксировано как правильное направление
- Единое приложение вместо набора разрозненных инструментов.
- Минималистичный Home и отдельный экран для глубокой аналитики.
- Ядро на базе учета времени Любищева + задач.
- Поэтапное расширение: сначала ядро, затем Mood/Habits, затем SMART Goals.

## 2) Текущий фокус разработки
Сейчас приоритет - **Wave A (Core)**:
- стабильность Time;
- стабильность Tasks;
- корректная привязка времени к задачам;
- ясная Home-сводка и детальный Reports.

## 3) Что добавить в ближайших итерациях (без перегруза)
1. В `Task details` блок "Потрачено: сегодня / всего".
2. В `Reports` режим анализа по задачам (топ задач по времени).
3. На Home индикатор "доля времени без задачи" как сигнал дисциплины.
4. В Time мягкая защита от случайного старта не той категории.

## 4) Mood + Habits (дизайн рамка)
- Mood: один быстрый чек-ин 1-10 в день.
- Habits: список привычек, ежедневный чек, отдельный стрик на каждую привычку.
- Habit details: календарь выполнений + текущая и лучшая серии.

## 5) Goals (SMART + декларация)
- Цель описывается через SMART-поля.
- Декларация целей - отдельный смысловой экран.
- Каждый шаг цели должен быть связан с задачами и временем.
- В отчете должно быть видно: сколько времени реально ушло на каждую цель.

## 6) Что убрать из ближайшего горизонта
- Любые сложные "красивые" графики на Home.
- Расширенный multi-user и биллинг.
- Сложные рекомендательные механики до стабилизации ядра.

## 7) KPI личного использования
Через 2-3 недели ежедневного использования ты должен видеть:
- стабильно работающий учет времени без ручной рутины;
- понятный контроль выполнения задач;
- связь "куда ушло время" -> "почему выполнено/не выполнено";
- базовый ритм через mood/habits (после включения Wave B).
