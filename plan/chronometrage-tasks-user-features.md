# Пользовательские фичи модуля "Хронометраж + Задачи"

## 1. Главный пользовательский эффект
Пользователь быстро понимает:
- что делать сейчас;
- сколько уже сделал за день;
- куда ушло время без перегруза аналитикой.

## 2. Home (первый экран)
Что видит пользователь:
- краткий профильный блок;
- прогресс задач за день (например `6/7`);
- стрик дисциплины ("огонек");
- потраченные минуты за сегодня;
- быстрые кнопки: `Старт таймера`, `Новая задача`, `Открыть сводку`.

UX-цель:
- за 5-10 секунд понять состояние дня.

## 3. Задачи
Пользователь может:
- создавать и редактировать задачи;
- выставлять приоритет (`high`, `medium`, `low`, `none`);
- указывать срок (опционально);
- добавлять заметки;
- вести подзадачи как чеклист;
- отмечать задачу выполненной.

UX-цель:
- ежедневное планирование без сложных форм и лишних полей.

## 4. Хронометраж
Пользователь может:
- запустить таймер с обязательным выбором категории;
- по желанию выбрать задачу сразу;
- остановить таймер и при необходимости привязать запись к задаче позже;
- добавить интервал вручную задним числом;
- отредактировать или удалить запись.

Категории по умолчанию:
- Работа
- Учеба
- Полезный досуг
- Дом
- Здоровье
- Потерянное время

UX-цель:
- быстро логировать время даже если задача не была заведена заранее.

## 5. Лента времени (Time Log)
Пользователь видит:
- интервалы времени за день;
- категории каждого интервала;
- суммарное время по дню.

Пользователь может:
- исправлять ошибки в интервалах;
- допривязывать записи к задачам;
- удалять лишние записи.

UX-цель:
- легко восстановить картину дня и исправить неточности.

## 6. Сводка дня
Режим 1 (кратко):
- выполнено задач;
- план/факт по времени;
- топ категорий дня.

Режим 2 (подробнее):
- детализация по категориям;
- список завершенных задач;
- отклонение от плана.

UX-цель:
- сначала быстрый вывод, потом детали по нажатию.

## 7. Уведомления
Нужны:
- мягкое напоминание начать день;
- мягкий прогресс-пинг (например "Осталась 1 задача").

Не нужны:
- навязчивые уведомления про остановку таймера;
- обязательные напоминания про ревью дня.

UX-цель:
- поддерживать ритм без давления.

## 8. Визуальный стиль
- минималистичный интерфейс;
- аккуратная типографика и отступы;
- минимум шумных элементов;
- акцент на ясность, а не на декоративность.

## 9. Сценарий "идеальный день" (MVP)
1. Пользователь открывает Home и видит краткий статус дня.
2. Создает/уточняет список задач.
3. Запускает таймер с категорией.
4. По мере работы закрывает задачи и подзадачи.
5. Вечером открывает сводку: что сделал и куда ушло время.

## 10. Критерий пользы модуля
Модуль полезен, если пользователь каждый день:
- не теряется в задачах;
- быстро запускает хронометраж;
- получает понятную и короткую обратную связь о дне.
