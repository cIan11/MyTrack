# Пользовательские фичи (Модуль 1: Time + Tasks + Stats)

## 1. Главный эффект
Пользователь всегда понимает:
- над чем работает сейчас,
- сколько уже сделал,
- куда ушло время.

## 2. Time
Пользователь может:
- выбрать категорию и запустить фокус-сессию;
- запускать таймер прямо из задачи (`play`);
- поставить на паузу, продолжить, завершить;
- завершить сессию без задачи и при желании создать задачу из этой сессии.

## 3. Tasks
Пользователь может:
- быстро добавлять задачи;
- задавать приоритет, срок, категорию, заметки;
- добавлять подзадачи чеклистом;
- отмечать выполнение;
- видеть время, потраченное на задачу.

## 4. Home (кратко)
Пользователь видит 4-6 метрик:
- фокус-время на задачах за сегодня;
- выполнено задач;
- среднее время на задачу;
- топ категория дня.

## 5. Reports (детально)
Пользователь открывает отдельный экран анализа и видит:
- период (день/неделя/месяц);
- факт по времени;
- расклад по категориям;
- доминирующую категорию;
- план/факт в духе учета Любищева.

## 6. UX принципы
- На основном экране только самое важное.
- Детальный анализ только на отдельном экране.
- Любое ключевое действие выполняется в 1-2 нажатия.
- Интерфейс минималистичный и предсказуемый.

## 7. Сценарий дня
1. Открыть Home и увидеть текущий статус.
2. Перейти в Tasks и определить, что делать.
3. Запустить таймер из конкретной задачи.
4. Закрыть задачу, посмотреть краткий результат на Home.
5. Вечером открыть Reports для детального анализа.
