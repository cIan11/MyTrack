# Product Backlog (Single-User First)

## Контекст
Бэклог обновлен под 3 модуля:
1. Time + Tasks + Stats (ядро)
2. Mood + Habits
3. Goals (SMART + декларация)

## Product Rules
- `iOS-first`, Expo.
- Минимализм UI, без аналитической перегрузки Home.
- Короткая сводка на Home, детали в `Reports`.
- Для таймера категория обязательна.
- Для настроения: ровно 1 запись в день.
- Для привычек: отдельный стрик и календарь по каждой привычке.

### Backend
- [ ] A-BE-01. Завершить модели задач/подзадач/тайм-энтри/категорий.
