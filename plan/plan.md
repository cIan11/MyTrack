# LifeTracker - Единый продуктовый план

## 1. Визия продукта
LifeTracker - одно личное iOS-приложение для управления:
- временем (по Любищеву),
- задачами и ежедневником,
- настроением и привычками,
- целями по SMART.

Ключевая идея: заменить несколько разрозненных инструментов одним минималистичным приложением.

## 2. Принципы
- Минимализм интерфейса важнее количества функций на экране.
- Главный экран отвечает на вопрос: "как у меня день прямо сейчас?".
- Короткая сводка на Home, детальный анализ на отдельной странице.
- Все метрики должны помогать действовать, а не перегружать.
- `single-user first`: сначала личный инструмент, потом масштабирование.

## 3. Архитектура модулей

### Модуль 1 (ядро): Time Tracking + Tasks + Статистика
- Таймер с обязательной категорией.
- Задачи с приоритетами, дедлайнами, подзадачами, заметками.
- Привязка времени к задаче.
- Короткий дашборд и отдельный экран подробной аналитики.

### Модуль 2: Mood + Habits
- Настроение: 1 запись в день, шкала 1-10.
- Привычки: отдельный стрик для каждой привычки.
- Для каждой привычки календарь выполнений.
- Простая связка с продуктивностью (корреляция на уровне наблюдения, без сложной науки).

### Модуль 3: Goals (SMART)
- Цели по SMART с дедлайном и метрикой результата.
- "Декларация целей" (вдохновлено подходом А. Бакшта).
- Разбиение целей на шаги/проекты/задачи.
- Связь целей с фактическим учетом времени по Любищеву.

## 4. Информационная архитектура экранов
1. `Home` - короткая сводка по всем модулям (без перегруза).
2. `Time` - фокус-сессия и управление текущим учетом времени.
3. `Tasks` - ежедневник задач.
4. `Reports` - подробная аналитика времени и задач.
5. `Habits` - привычки, стрики, календарь.
6. `Goals` - SMART-цели и декларация.

## 5. Home: что показывать (минимум)
До добавления Mood/Habits:
- Фокус-время на задачах за сегодня.
- Выполнено задач / всего.
- Среднее время на задачу.
- Топ категория дня.

После добавления Mood/Habits:
- Настроение сегодня (1-10).
- Стрик ключевой привычки.
- Кнопка "Подробный анализ".

Правило:
- не более 4-6 карточек на Home.

## 6. Данные (прикладная модель)
- `tasks`
- `task_subtasks`
- `time_entries`
- `activity_categories`
- `mood_entries` (1 запись в день)
- `habits`
- `habit_logs`
- `goals`
- `goal_milestones`
- `goal_declaration`
- `daily_snapshots` (агрегаты для Home/Reports)

## 7. Roadmap (волны)

### Волна A - Стабилизация ядра (сейчас)
- Довести Time + Tasks UX до стабильного состояния.
- Закрыть edge-cases таймера и привязки времени к задачам.
- Финализировать Home (короткая сводка) и Reports (детали).

### Волна B - Mood + Habits
- Экран настроения: 1 оценка в день (1-10).
- Экран привычек: список привычек, отметка выполнения, стрик, календарь.
- Легкая аналитика: динамика настроения, % выполнения привычек.

### Волна C - SMART Goals
- CRUD целей и декларации целей.
- SMART-поля + статус прогресса.
- Связь целей с задачами и временем.
- Отчеты: время на цели, прогресс целей.

## 8. Definition of Done (продукт v1)
Приложение готово к ежедневному личному использованию, если ты можешь:
1. Планировать и закрывать задачи.
2. Вести непрерывный учет времени с категориями.
3. Видеть краткую дневную картину и детальную аналитику.
4. Отмечать настроение ежедневно.
5. Вести привычки со стриками и календарем.
6. Формулировать SMART-цели и отслеживать прогресс через время/задачи.

## 9. Что откладываем
- Публичный multi-user режим и биллинг.
- Сложные ML-рекомендации.
- Интеграции с внешними календарями/трекерами до стабилизации ядра.
